# Predicción de Deserción Estudiantil con Machine Learning

## Descripción del proyecto

Proyecto académico de análisis de datos y aprendizaje automático orientado al estudio de la deserción estudiantil.

El objetivo es explorar información relacionada con estudiantes y aplicar técnicas de Machine Learning para estudiar la posibilidad de predecir la deserción a partir de las variables disponibles en el conjunto de datos.

Este proyecto permite abordar un problema educativo mediante un enfoque basado en datos y explorar el uso de modelos predictivos como apoyo al análisis.

## Objetivos

- Comprender la estructura y las características de los datos educativos.
- Explorar las variables relacionadas con la información estudiantil.
- Preparar los datos para su utilización en modelos predictivos.
- Aplicar técnicas de Machine Learning al problema planteado.
- Examinar y evaluar los resultados obtenidos.
- Comprender las posibilidades y limitaciones de la predicción basada en datos.

## Metodología

El flujo de trabajo contempla las siguientes etapas, de acuerdo con las operaciones desarrolladas en el notebook:

1. **Exploración de datos:** inspección de la información disponible.
2. **Preparación de datos:** revisión y transformación de variables cuando sea necesario.
3. **Construcción del modelo:** aplicación de técnicas de Machine Learning.
4. **Evaluación:** análisis de las predicciones y de las métricas disponibles.
5. **Interpretación:** revisión de los resultados en el contexto del problema educativo.

## Consideraciones

La predicción de deserción estudiantil es un problema que requiere especial cuidado al interpretar los resultados. Un modelo predictivo no demuestra por sí solo causalidad ni debe utilizarse como único criterio para tomar decisiones sobre estudiantes.
